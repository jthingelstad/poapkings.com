# Assets — fonts and imagery

Most files here are POAP KINGS' own art (`poapkings.png`, `elixir.png`, `404.jpg`,
`favicon/`, `icons/`). Two categories are **Supercell's** intellectual property, used
as fan kit assets under Supercell's Fan Content Policy:

## Fonts — `Clash_Regular.otf`, `Clash_Bold.otf`

Supercell's official **Clash** display font (© 2016 Supercell, designed by John
Roshell / Comicraft), from the Supercell Fan Kit (<https://fankit.supercell.com/>).
"Clash" is a trademark of Supercell.

- Served locally (bundled) so the wordmark and display type render reliably without a
  third-party font CDN.
- Used **unmodified** (referenced via the `Clash` `@font-face` in `../styles.css`); the
  files are not altered. The policy prohibits modifying Supercell Assets.
- History: this repo previously shipped a third-party lookalike (`Supercell-Magic-Regular.ttf`,
  © Active Images 2009 — internally the Comicraft "You Blockhead" font renamed), which is
  **not** a genuine Supercell asset. It was replaced with this official Fan Kit font.
